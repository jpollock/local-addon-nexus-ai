TURN 2 — THE BASKET, TAKEN SERIOUSLY
If being wrong is expensive, make being wrong visible
Two refinements of 1b. Both keep the readable basket; they disagree about when to make you look at it. 2a makes the basket itself the warning surface — production sites stand out inside your own list. 2b adds a deliberate review step: you cannot run until you have seen a plain-language summary of what is about to happen.
2a Basket that flags itself
The basket groups by environment with production pinned to the top in red. Adding a production site is never quiet — the group appears, the footer changes colour, and the run button names the number. No extra step, no modal on top of a modal.

TURN 1 — SITE PICKER, RETHOUGHT
Three ways to choose sites
Environment is no longer a filter — it is information shown on the row. Platform is the only filter, and it now has three values: WP Engine, Local, External. Each option below is fully interactive. 1a and 1b are lists with different selection models; 1c argues that most people should never see a list at all.
1a Grouped — no filters, check at any level
Sites are grouped by environment, so environment is structure rather than a filter. Each group header selects the whole group. There is no filter row, no bulk-action bar, and no side rail — the footer carries the count. Fastest path to "all staging plus these two."
