## 1 · The variant, ruled: 1a is the session's shape; 1b's empty run is the empty run

**1a is ratified as the layout.** The block pinned to the top of the
session while the run is in force is XD-3 rendered as geometry — the
procedure outranks the transcript, so it holds the top and the turns
move beneath it. The fold-in-place on finish is the half of the rank
model 1b gives up: the record does not move, so the thing she read
before the run is the thing she reopens after it, which is RB-E 2b's
own caption ("the run finished, so it stops being primary") at the
narrower width. And the yield rule — while an approval card is up the
block gives back space and holds 200px, never the reverse — is
ceremony-scales-with-consequence (XD-5) as a layout law: the decision
outranks the declaration while the run is waiting on one. That
sentence in your rationale is now the pin.

**1b as a layout is refused, on your own cost line.** "A mode you can
leave is a mode you can lose track of — the bar is doing a lot of
work" is the refusal's whole argument: rank is promotion, not
navigation (§0, XD-3), and 1b makes the run's rank a place you travel
to and from. Its finished state compounds it — a record "reachable
from the bar, not resident" is promotion made lossy. The bar was doing
a lot of work because it was doing navigation's work.

**But 1b's empty run is the ruled one, and 1a's is refused.** RB-E 2c
states the doctrine better than we had it: no consequence, no rank, no
container. An armed block whose six checkpoints dash themselves "not
applicable" is a container pretending to be work, and the dash is a
fourth mark meaning nothing-attests — vocabulary by drift. Your own
sibling sheet had already refused it: RB-E's closing contract makes
"what an empty plan produces" seam-governed, and seam-governed facts
may not diverge between densities. So the composite is ruled: **RB-D
final = 1a's waiting and finished states, 1b's empty state.** The
refusal stays a turn, the derived plan attaches verbatim, the
alternatives are offers.
