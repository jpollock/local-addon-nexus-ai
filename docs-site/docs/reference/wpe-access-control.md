# WPE Access Control (superseded)

This page described the pre-v2 access-control model and has been retired.

**See [Permissions & Access Control v2](permissions-access-control-v2.md)** —
the current model: per-operation permissions (`wpcli_read` / `wpcli` / `push` /
`delete`) per environment, with per-site exceptions, configured in the
Settings tab.
